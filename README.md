# STUK  
A digital student card for Adriana

## How to Use

1. Open this link on your mobile device:  
   **[axelaaberg.github.io/STUK](https://axelaaberg.github.io/STUK)**

2. Add the web app to your home screen:  
   - On **iPhone (Safari)**: Tap the **"Share"** button → Select **"Add to Home Screen"**  
   - On **Android (Chrome)**: Tap the **⋮** menu → Select **"Add to Home screen"** → Select **"Install app"**

3. Done! You can now access STUK just like a native app.

## ℹ️ About the Project

This project is a lightweight prototype of a digital student card created for Adriana.  
It is optimized for mobile use and designed to be quickly accessible from the home screen.
QR-code does not work for obvious reasons.
